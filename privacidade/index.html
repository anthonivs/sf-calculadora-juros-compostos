Política de Privacidade

Última atualização: 10 de outubro de 2026.

Esta política explica, de forma simples e em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), como a Calculadora de Juros Compostos trata (ou melhor, deixa de tratar) informações de quem a utiliza.

1. Não coletamos dados pessoais

Esta é uma ferramenta 100% client-side. Todos os cálculos acontecem no seu próprio navegador. Não existe cadastro, login, formulário de contato com envio de dados, banco de dados nem back-end que receba o que você digita. Os valores que você informa (valor inicial, aportes, taxa, período, inflação) não são enviados para nenhum servidor.

2. Armazenamento local e cookies

Atualmente o site não usa cookies de identificação, localStorage ou sessionStorage. Os cenários comparados ficam apenas na memória da página e desaparecem ao recarregá-la. Os parâmetros da simulação podem ser compartilhados por você via query string na URL (por exemplo, ao usar o botão “Copiar link da simulação”); esses parâmetros ficam apenas na barra de endereços e são lidos pelo próprio navegador.

3. Dados de acesso (hospedagem)

O site é hospedado em serviço de hospedagem estática (por exemplo, GitHub Pages). Como qualquer servidor web, o provedor de hospedagem pode registrar dados técnicos de acesso, como endereço IP, data/hora e user-agent, para fins de segurança e funcionamento. Esses registros são tratados pelo provedor de hospedagem, não por esta ferramenta, e não são usados para identificar você.

4. Publicidade (anúncios)

Este site ainda não exibe anúncios. Caso a publicidade seja ativada no futuro (por exemplo, via Google AdSense), provedores de anúncios poderão usar cookies e tecnologias semelhantes para exibir e medir anúncios. Nesse cenário, será implementado previamente um mecanismo de consentimento (CMP) compatível com a LGPD e o GDPR, e esta política será atualizada para refletir os dados tratados, as finalidades e as opções de consentimento e de recusa.

5. Seus direitos (LGPD)

Como não tratamos dados pessoais identificáveis, não há dados seus para acessar, corrigir ou excluir nesta ferramenta. Ainda assim, caso tenha dúvidas sobre privacidade, você pode contatar o responsável indicado abaixo.
